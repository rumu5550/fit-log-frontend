# FitLog

> **Train with intent. Log every set.**  
> A modern, dark-themed workout tracking web application designed for gym enthusiasts to discover exercises, build a targeted daily plan, and track training sessions seamlessly.

---

## ⚡ Technologies Used

- **Framework**: Next.js 16 (App Router with Turbopack)
- **Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Data Persistence**: LocalStorage & React Context API

---

## ✨ 5 Key Features

1. **🏋️ Exercise Library & Smart Search**
   - Browse a comprehensive workout catalog with high-resolution imagery, target muscle groups, required equipment, duration, calories burned, sets, reps, and ratings.
   - Real-time search and filter by exercise name or muscle group tags (`Chest`, `Back`, `Quads`, `Shoulders`, etc.).

2. **📋 Daily Plan with 5-Lift Cap**
   - Create a focused daily routine with a 5-exercise maximum capacity constraint to maintain training quality and prevent overtraining.
   - Action buttons automatically display real-time status (`Added to today's plan` / `Plan Full (5/5)`).

3. **📊 Real-time Workout Metrics**
   - Interactive dashboard on the **My Plan** page calculating total exercises, combined training duration in minutes, and total estimated calorie expenditure.

4. **🔄 Workout Completion & Organization**
   - Mark lifts as completed with real-time visual progress tracking and strike-through styling.
   - Dynamic sorting options by duration, calories burned, or rating.
   - Save workouts for later into a dedicated **Saved** tab.

5. **⚡ Fast Loading Animations & Responsive Dark Design**
   - Shimmering skeleton loading state on the exercise library and dedicated spinner indicators on plan retrieval.
   - Fully optimized and mobile-responsive dark interface tailored for gym-floor usage across smartphones, tablets, and desktops.
